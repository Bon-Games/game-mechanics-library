# Migration baseline audit

The implementation began on local `master` at `f2ce28d`. Before implementation,
`.gitignore`, `AGENTS.md`, `docs/`, and `web/` were untracked local work. They were
inspected and reused where compatible; the legacy root site was preserved.

The original data was frozen before conversion in `web/tests/fixtures/legacy/`:

| Original | SHA-256 |
|---|---|
| `data/mechanics.txt` | `9c5b5d51839144ba300cd8063c9e12d373210f27210794e6178a749636a4138f` |
| `data/sources.json` | `07add6296f00e9752cc247b2edbeb91b7244ce5f31a47d068ebaae9d3768f488` |

The migration authority is these originals, not the scaffold's generated records.
The baseline is 763 distinct names, 20 categories, and six source records.
Duplicate names retain their first-seen classification, matching legacy `parseSeed`.
The deterministic mapping and duplicate report are generated by the migration tool.

| Scaffold area | Decision and reason |
|---|---|
| Astro/React/Tailwind/Pagefind dependencies | Reuse compatible released versions after registry/peer review; install and validate using Node 24. The old audit file is stale evidence, not the dependency disposition. |
| Content collection loaders | Reuse the glob-loader approach; correct schema vocabulary and identity validation. |
| Converted Markdown and registry files | Correct to the canonical contracts; preserve names and original registry values. |
| Domain schema and validation | Replace conflicting category/related/researched fields and incomplete provenance. |
| Framework loader under domain | Move into the framework adapter layer. |
| URL helpers and browsing island | Correct normalization, real full-text search, history, failure recovery, and responsive pagination. |
| Page templates and CSS | Refine against the agreed purple/navy application design and complete static navigation. |
| Build verifier and tests | Extend to negative fixtures, publication isolation, hosting modes, and actual indexed browser journeys. |
| Existing deployment workflow | Replace repository-root upload with validated `web/dist/` and an explicit master release gate. |
| Root HTML/CSS/JS/data | Retain as a rollback source; exclude from the new public artifact. |

Legacy shared state includes `q`, `category`, `subcategory`, `source`, `sort`,
`view`, `page`, and `lang`; category/subcategory display labels remain accepted.
Home anchors `home`, `library`, `contribute`, and `about` remain available.
The custom domain is `mechanics-lib.bongames.org`.

Gateway tools for AgentMemory/Graphify/Playwright were not exposed and the configured
localhost port 8811 was unreachable. Local source inspection and host Playwright
are the fallback for this implementation; no remote system was modified.
